개인정보 처리방침

Tsumiage는 사용자의 정보를 전혀 수집하지 않아요.
최종 수정일: 2026년 10월 11일

저장하는 정보

  • 목표, 기록(숫자·메모·날짜), 화면 설정은 사용 중인 iPhone 안에만 저장돼요. 홈 화면 위젯도 같은 iPhone 안의 데이터를 읽어요.
  • 개발자 서버도, 회원 가입도 없어요.
  • 앱을 삭제하면 이 데이터는 모두 사라져요.

사용하는 기능

  • 알림: 매일 리마인더를 켰을 때만 iPhone 안에서 예약한 알림을 보내요. 외부로 보내지 않아요.
  • Face ID / Touch ID: 앱 잠금을 켰을 때만 iOS가 본인 확인을 해요. 앱은 얼굴이나 지문 데이터를 받지 않아요.
  • CSV 내보내기: 직접 내보내기를 선택했을 때만 기록을 파일로 만들어 공유 시트에 넘겨요.
  • 구매: Tsumiage Pro 결제는 Apple이 처리해요. 개발자는 결제 정보를 받지 않아요.

수집하지 않는 정보

광고, 추적, 분석, 충돌 수집 도구를 사용하지 않아요. 구매할 때 App Store와 통신하는 것 말고는 인터넷에 연결하지 않아요.
