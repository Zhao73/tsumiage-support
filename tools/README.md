# ツミアゲ site tools

The public site (https://zhao73.github.io/tsumiage-support/) is plain static HTML generated by these scripts. Edit the scripts, not the generated `.html` files.

## Run

```sh
cd tools && npm install            # once (Playwright, used for PDFs and checks)
npx playwright install chromium-headless-shell   # once
cd ..
node tools/build.mjs               # writes every page, sitemap.xml, robots.txt, llms.txt, llms-full.txt
node tools/render.mjs              # icons, OG images (assets/og/), printable PDFs + previews (pdf/)
node tools/verify.mjs              # links, JSON-LD, hreflang, overflow, tracker test
node tools/verify.mjs --shots DIR  # same + desktop/phone, light/dark screenshots
```

`node tools/math.mjs` checks every total quoted on the site (137,800円, 66,795円, $1,378 …).

## Files

| File | What it holds |
| --- | --- |
| `lib.mjs` | Shared layout (head, header, footer), components, `APP_PT` campaign token |
| `challenge.mjs` | Template for one challenge page |
| `pages-ja.mjs` / `pages-en.mjs` / `pages-ko.mjs` | All copy, per language |
| `math.mjs` | Challenge maths + self-test |
| `../assets/site.css`, `../assets/site.js` | Styles and small enhancements (site works without JS) |

## App screenshots

Drop real App Store screenshots in `assets/shots/01.png` … `04.png` (portrait) and run `node tools/build.mjs`. The landing pages show the screenshot section only when those files exist.

## Design notes

- Colours: canvas `#F4F6F3` / dark `#0C100E`; brand gradient `#69E090 → #2DC88E → #11B6A5` (from the app icon); links `#0A7550` / dark `#4FE3A3`; 500円玉 gold for coin motifs.
- Fonts (all open licence): Zen Kaku Gothic New (Japanese), Manrope (Latin and numerals), Pretendard (Korean). Do not use private fonts here — this repo is public.
- Signature moment: the hero ring closes while three capsules drop in and the total counts up to ¥137,800 / $1,378 / ₩1,378,000. Reduced-motion users get the final state.
